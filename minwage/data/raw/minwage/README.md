# State minimum wage changes

`state_mw_changes_1974_2022.csv` and `federal_mw_changes.csv` are converted from
the raw spreadsheets of the Vaghul-Zipperer historical minimum wage repository
(https://github.com/benzipperer/historicalminwage, `rawdata/`), fetched
2026-09-12; one row per effective date of a new state (or federal) minimum.
The list ends 31 December 2022. **Changes from January 2023 onward must be
added** from the state schedules before the events for 2023-2025 are defined.
The event list for the enrollment design is built by `python/30_build_mw_events.py`.
